# Pandas

Introduction to the pandas library for loading, cleaning, and
manipulating tabular data.

## Description
Scripts that create DataFrames from NumPy arrays, dictionaries, and
files, then rename, slice, sort, and analyze tabular data.

## Requirements
- Python 3.9, pandas 2.x, numpy
- pycodestyle 2.11.1
- Each file starts with `#!/usr/bin/env python3`

## Tasks
0. From Numpy – DataFrame from an ndarray
1. From Dictionary – DataFrame from a dict
2. From File – load a CSV into a DataFrame
3. Rename – rename and convert a timestamp column
4. To Numpy – last rows as an ndarray
5–14. Slice, Flip, Sort, Prune, Fill, Index, Concat, Hierarchy,
       Analyze, Visualize
