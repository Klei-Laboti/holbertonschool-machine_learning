# Plotting

Introduction to data visualization with matplotlib.

## Description
Scripts that produce line graphs, scatter plots, histograms, bar
charts, and multi-plot figures using matplotlib.pyplot.

## Requirements
- Python 3.9, matplotlib, numpy
- pycodestyle 2.11.1
- Each file starts with `#!/usr/bin/env python3`

## Tasks
0. Line Graph – solid red line
1. Scatter – height vs weight
2. Change of scale – logarithmic y-axis
3. Two is better than one
4. Frequency – histogram
5. All in One – multiple plots in one figure
6. Stacking Bars
