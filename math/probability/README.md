# Probability

Classes that represent common probability distributions, built from
scratch without importing any module. Irrational constants are
approximated by hand (π = 3.1415926536, e = 2.7182818285).

## Requirements
- Ubuntu 20.04 LTS, Python 3.9
- pycodestyle 2.11.1
- No imports allowed
- All files start with `#!/usr/bin/env python3` and are executable

## Files
| File | Description |
|------|-------------|
| `exponential.py` | `Exponential` class: constructor, `pdf(x)`, `cdf(x)` |
